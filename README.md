# EcoCare Smart Field Sales Assistant

Aplikasi Web Dashboard **Asisten Lapangan (Door-to-Door Sales Prospecting)** untuk Tim Sales **PT EcoCare Indo Pasifik Tbk** dengan fitur:
- **Interactive Observation Checklist Form**: Profil Gedung, Observasi Hygiene, Pest Control, Termite Control (Anti-Rayap), serta Fumigasi & Vendor.
- **AI Predictive Lead Scoring & Next Best Offer (NBO) Engine**: Menghitung probabilitas konversi (Hot/Warm/Cold Prospect), rekomendasi lini utama, cross-selling, dan panduan pitching produk spesifik EcoCare.
- **Ringkasan & Riwayat Kunjungan**: Penyimpanan sesi lokal (`LocalStorage`) dilengkapi fitur filter, pencarian, dan export JSON.

## Cara Menjalankan di Lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.
